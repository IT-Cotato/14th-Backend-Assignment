# 기능 구현 계획 수립

## 절차

1. 사용자의 요청을 미러링한다. ("이렇게 이해했습니다: ...")
2. 모호한 점이 있으면 질문한다. 아래 항목을 확인한다:
   - 어떤 엔드포인트가 필요한가? (HTTP 메서드, URL)
   - Request/Response 형식은?
   - 예외 케이스는? (존재하지 않는 ID, 중복 등)
   - 기존 코드에 영향을 주는 부분이 있는가?
3. 질문에 대한 답을 받은 후, 구현 계획을 작성한다:
   - 생성/수정할 파일 목록
   - 각 파일에서 할 작업 요약
   - 완료 조건 (빌드 성공, Swagger 확인 등)
4. 사용자의 승인을 받은 후에만 코드 작업을 시작한다.

## 하지 말 것

- 승인 없이 코드를 작성하지 않는다.
- 요구사항이 불명확한 상태에서 추측으로 구현하지 않는다.
- 한 번에 여러 API를 계획하지 않는다. API 1개 단위로 진행한다.
