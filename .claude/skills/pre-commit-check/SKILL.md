# 커밋 전 점검

커밋하거나 PR을 올리기 직전에 다음 순서로 점검한다.

1. **git status 확인**
   - `git status`로 변경/추가된 파일 목록을 확인한다.
   - `.env`, `application-local.yml`, `*.pem`, `*.key` 등 민감 파일이 스테이징 대상에 없는지 확인한다.

2. **민감 파일 재확인**
   - `git diff --cached --name-only`로 실제 스테이징된 파일만 다시 확인한다.
   - 민감 파일이 보이면 커밋하지 말고 사용자에게 먼저 알린다.

3. **빌드/테스트 확인**
   - `./gradlew build` (또는 최소 `./gradlew test`)를 실행해 빌드가 깨지지 않았는지 확인한다.
   - 실패하면 원인을 보고하고, 커밋을 진행하지 않는다.

4. **요약 보고**
   - 위 점검 결과를 간단히 요약해서 사용자에게 보고한 뒤 커밋을 진행한다.
