# 엔티티 변경 규칙

- 테스트 없이 엔티티 구조를 변경하지 않습니다. 관련 테스트를 함께 작성합니다.
- 변경 전에 추가, 삭제, 변경되는 컬럼과 기존 데이터에 미치는 영향을 사용자에게 알립니다.
- 테스트를 실행하면 `ddl-auto: update`가 실제 로컬 DB에 적용될 수 있으므로, 실행 전에 이 점을 사용자에게 알립니다.
- 컬럼 삭제나 타입 변경은 절차를 사용자와 먼저 정합니다.
- 새 엔티티는 `BaseEntity`를 상속합니다.
- 자세한 절차는 `docs/database.md`를 따릅니다.
