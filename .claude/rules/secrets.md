# 민감 정보 규칙

- `.env`를 열거나 수정하거나 내용을 출력하지 않습니다. 키 이름 확인도 포함합니다.
- `.env`가 Git에서 제외되는지는 `git check-ignore .env`로 확인합니다.
- 비밀번호나 토큰을 yml, 코드, 로그, 커밋, 문서에 직접 쓰지 않습니다.
- yml에서는 `${환경변수}` 참조만 사용합니다.
- `.env`의 값이 필요하면 사용자에게 필요한 이유를 말하고, 사용자가 직접 확인하도록 요청합니다.
- 민감한 값이 노출된 것을 발견하면 값을 반복해서 출력하지 말고 위치만 사용자에게 알립니다.
