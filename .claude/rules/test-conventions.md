# 테스트 코드 작성 규칙

## 기본 원칙

- 테스트는 JUnit Platform 기반으로 작성한다.
- 기존 테스트 코드의 구조와 네이밍 방식을 따른다.
- 테스트는 독립적으로 실행할 수 있도록 작성한다.
- 테스트의 실행 순서에 의존하지 않는다.

## 테스트 작성

- 정상적인 동작뿐 아니라 주요 예외 상황도 검증한다.
- 테스트 이름은 검증하려는 동작을 이해할 수 있도록 작성한다.
- 테스트에 불필요한 외부 의존성이 생기지 않도록 주의한다.
- 테스트 데이터는 각 테스트의 목적을 이해할 수 있도록 구성한다.

## 테스트 검증

- 관련 테스트를 실행한다.
- 실패한 테스트를 임의로 삭제하거나 비활성화하지 않는다.
- 테스트가 실패하면 원인을 확인한 후 수정한다.
- 테스트 실행 여부와 결과를 보고한다.
