# E2E 테스트 규칙

- 요소는 `getByRole`, `getByLabel`, `getByText`로 찾는다. CSS 선택자, `nth-child`, 클래스 이름에 기대지 않는다.
- `page.waitForTimeout` 같은 고정 대기를 쓰지 않는다. `expect(...)`의 자동 대기를 쓴다.
- 테스트마다 데이터를 새로 만든다. 이메일은 `e2e-` + 고유값, 닉네임과 글 제목도 고유값을 붙인다. 다른 테스트가 만든 데이터에 기대지 않는다.
- 비밀번호를 코드에 적지 않는다. `helpers.ts`의 `testPassword()`(환경 변수 `E2E_PASSWORD` 또는 실행마다 무작위 값)를 쓴다.
- 준비 단계(회원가입, 글 작성)는 API로 빠르게 하고, 검증하려는 흐름은 화면으로 조작한다.
- 화면에서 숨긴 동작(남의 글 수정, 마감 글 댓글)은 API를 직접 호출해 403/409가 오는지도 확인한다.
- 실패하면 원인이 앱인지 테스트인지 먼저 가린다. 통과시키려고 테스트를 지우거나 검사를 약하게 바꾸지 않는다.
- 같은 DB를 쓰므로 `workers: 1`로 순서대로 돌린다.
