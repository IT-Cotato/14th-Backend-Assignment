# E2E 테스트 규칙

## 요소 찾기
- 요소는 `getByRole`, `getByLabel`, `getByText`로 찾는다. CSS 선택자를 쓰지 않는다.

## 대기
- `waitForTimeout` 같은 고정 대기를 쓰지 않는다. `expect`가 조건이 맞을 때까지 기다린다.

## 테스트 데이터
- 테스트마다 독립이다. 이메일, 닉네임, 글 제목은 매번 새로 만든다. (타임스탬프 등)
- 다른 테스트의 데이터에 기대지 않는다.
- 테스트 계정 이메일은 `e2e-`로 시작한다.
- 비밀번호를 코드에 적지 않는다. 실행할 때 만들거나 환경 변수로 받는다.

## 검증
- 화면에서 숨긴 동작(남의 글 수정 등)은 API를 직접 호출해 403, 409가 오는지도 확인한다.

## 실패 처리
- 실패하면 원인이 앱인지 테스트인지 먼저 가린다.
- 통과시키려고 테스트를 지우거나 검사를 약하게 바꾸지 않는다.

## 실행
- 실행은 레포 루트에서 `npm --prefix frontend run test:e2e`로 한다.
- 백엔드 서버는 사람이 켜둔다. 테스트를 위해 백엔드를 직접 띄우지 않는다.
