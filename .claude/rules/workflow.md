# 협업과 제출

- 개인 누적 브랜치는 `seonjae/basic`, 하네스 작업 브랜치는 `seonjae/harness`다.
- 하네스 PR의 base는 `seonjae/basic`이다. `develop`으로 제출하지 않는다.
- 커밋은 `chore: 요약`, `docs: 요약`처럼 변경 성격에 맞는 타입을 붙인다.
- 과제 PR 제목은 `chore: [윤선재] 4주차 하네스 구축 (closes #105)` 형식을 따른다.
- PR에는 각 문서·규칙·스킬·훅을 만든 이유와 검증 결과를 적고 `closes #105`를 연결한다.
- stage 전에 변경 목록을 확인한다. `.env`, 빌드 결과, 개인 설정은 포함하지 않는다.
- 테스트와 실제 실행 결과를 구분하고, 실행하지 않은 검증을 완료했다고 적지 않는다.
- PR 병합은 파트장이 진행한다.
