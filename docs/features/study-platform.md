# 코테이토 스터디 매칭 플랫폼 기능 구현

## 1. 개요

기존 네이버 카페에서 진행하던 스터디 모집 및 신청 과정을 웹 서비스로 구현한다. 회원 인증, 스터디 모집글 관리, 댓글을 통한 스터디 신청 기능을 프론트엔드와 백엔드에서 통합 구현했다.

## 2. 인증 기능

### 주요 구현 내용
- 이메일과 비밀번호를 이용한 회원가입 및 로그인
- 기수와 파트(PM, DE, BE, FE) 정보 관리
- BCrypt 비밀번호 암호화 및 JWT 인증
- 로그아웃 시 발급된 토큰 무효화
- 마이페이지에서 사용자 정보 조회
- 인증 상태에 따른 화면 접근 제어

### 주요 고려사항
- 인증이 필요한 API와 공개 API 구분
- 유효하지 않은 JWT에 대한 예외 처리
- 회원가입 입력값 검증 및 중복 이메일 방지

## 3. 스터디 모집글 기능

### 주요 구현 내용
- 모집글 작성, 목록 조회, 상세 조회, 수정, 삭제
- 키워드 검색 및 모집 상태·작성자 파트 필터
- 페이지네이션과 최신순 정렬
- 모집 상태(RECRUITING, CLOSED) 변경
- 작성자에게만 수정 및 삭제 권한 부여

### 주요 고려사항
- 검색 조건을 조합할 때 AND 조건 적용
- 비로그인 사용자도 목록과 상세 조회 가능
- 작성자 권한을 서버에서 검증
- 모집글 삭제 시 관련 댓글 처리

## 4. 댓글(스터디 신청) 기능

### 주요 구현 내용
- 모집글에 댓글 작성, 조회, 수정, 삭제
- 댓글 작성자에게만 수정 및 삭제 권한 부여
- 댓글 목록 페이지네이션
- 모집 마감 상태에서는 새로운 댓글 작성 제한
- 모집 마감 이후에도 기존 댓글 수정 및 삭제 허용

### 주요 고려사항
- 모집 상태 변경과 댓글 작성이 동시에 발생할 때의 정합성
- 존재하지 않는 모집글이나 댓글에 대한 예외 처리
- 댓글 작성자 권한 검증
