# 코테이토 14기 백엔드 과제

코테이토 14기 백엔드 파트의 학기 중 과제 저장소입니다.
코딩테스트만큼 과제 전형의 비중이 커지고 있고, AI를 얼마나 잘 활용하는지도 중요하다고 생각해서 구성했습니다.

## 주차별 소개

### 📂 1주차: Git & GitHub
브랜치, 커밋, 이슈, PR 등 협업의 기본 흐름을 익힙니다.

### 📂 2주차: Swagger, .env 파일 설정
Swagger로 API 문서를 만들고, `.env`와 프로필로 환경 설정을 분리합니다.

### 📂 3주차: 공통 응답, CORS, Security, BaseEntity 설정
공통 응답 형식, 전역 예외 처리, CORS, Security, BaseEntity 등 기본 프로젝트 세팅을 합니다.

### 📂 4주차: 하네스 엔지니어링
`CLAUDE.md`, `rules`, `skills`, `hooks` 등 AI가 개발을 수행하도록 감싸는 나만의 구조를 만듭니다.

### 📂 5~6주차: 스터디 매칭 플랫폼 만들기
요구사항에 맞춰 백엔드 API부터, 바이브 코딩으로 만드는 프론트까지 직접 개발합니다.

## 진행 방식
- 처음 하는 분도 따라올 수 있도록 **1~3주차는 코드를 제공**하고, **4~6주차는 자료를 참고해 각자 개인 프로젝트**를 만듭니다.
- 주차별 리뷰 세션을 진행합니다.
- 기간 내 미제출 시 벌점 3점이 부여됩니다.

## 브랜치 & PR 규칙
- 각자 `이름/basic` 브랜치에 작업을 누적합니다.
- 주차 작업은 `이름/basic`에서 브랜치를 따서(예: `이름/harness`, `이름/monorepo`) 작업하고, PR은 `이름/basic`으로 올립니다.
- PR 제목: `타입: [이름] 내용 (closes #이슈번호)`
- 이슈 제목: `타입: [이름] 내용`
