# Frontend Guidelines

## 기술 스택

- React, TypeScript, Vite
- ESLint를 사용하여 코드 품질을 검사한다.

## 코딩 규칙

- TypeScript의 타입 시스템을 활용하고 불필요한 `any` 사용을 지양한다.
- React 함수형 컴포넌트와 Hooks를 사용한다.
- 컴포넌트는 하나의 명확한 책임을 갖도록 구성한다.
- 기존 프로젝트의 네이밍 및 파일 구조를 우선적으로 따른다.
- 불필요한 컴포넌트 분리나 추상화는 지양한다.
- 재사용 가능한 UI 요소는 필요할 때 공통 컴포넌트로 분리한다.

## 상태 및 API 처리

- 서버 데이터와 UI 상태를 구분하여 관리한다.
- API 요청과 관련된 로딩 및 오류 상태를 고려한다.
- 백엔드 API의 요청 및 응답 형식을 임의로 가정하지 않는다.
- 새로운 상태 관리 라이브러리를 도입하기 전에 필요성을 검토한다.

## 테스트 및 검증

- 기능 구현 시 주요 사용자 흐름과 예외 상황을 고려한다.
- ESLint 오류를 확인하고 해결한다.
- TypeScript 빌드 오류를 확인한다.
- 테스트 도구가 구성되어 있다면 관련 테스트를 실행한다.

## 검증 명령어

- 린트 검사: `npm run lint`
- 빌드: `npm run build`

위 명령어는 `frontend/` 디렉터리에서 실행한다.
